## 개요

### 나의 활동

매 회차 **논문 리뷰 → 모델 직접 구현 → 발표**를 반복했습니다. 읽고 끝내지 않고 반드시 돌려보는 것이 스터디 규칙이었습니다.

다룬 것: 논문 리뷰(Siamese CBOW 등) · CNN / RNN / LSTM 구현 · **ETRI Fashion-How Season 5** 참가(베이스라인 분석, 데이터 매핑 및 증강, ResNet 기반 모델링, 버전별 결과 비교).

### 핵심 성과 · Key Achievements

- **2년간 지속** **논문 리뷰 → 모델 직접 구현 → 발표**를 회차마다 반복했습니다. 읽고 끝내지 않고 반드시 돌려보는 것이 스터디 규칙이었고, 2023.07부터 2025.07까지 이어갔습니다

- **대회 참가로 검증** **ETRI Fashion-How Season 5**에 참가해 베이스라인 분석 · **데이터 매핑 및 증강** · ResNet 기반 모델링까지 직접 돌렸습니다

- **실험 기록 습관** 버전을 바꿔가며 **결과를 표로 남기는** 방식을 여기서 익혔습니다. 무엇을 바꿨을 때 무엇이 움직였는지 적어두지 않으면 다음 주에 같은 실험을 다시 하게 됩니다

- **기반이 된 것** 이후 Bimp의 YOLO 모델링, 영화 추천의 GMF/NNMF 비교 실험이 전부 이 스터디에서 만든 **“돌려보고 기록한다”** 절차 위에서 진행됐습니다

### 남은 것

버전을 바꿔가며 결과를 표로 남기는 습관이 여기서 왔습니다. 무엇을 바꿨을 때 무엇이 움직였는지 기록해두지 않으면, 다음 주에 같은 실험을 다시 하게 됩니다.

**자료 정리 중입니다.** 2년치 노트북과 발표자료가 흩어져 있어 공개 저장소로 묶지 못했습니다. 필요하시면 개별 자료로 보내드립니다.
