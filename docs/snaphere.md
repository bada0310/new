## 개요

### 진행 상황

한국관광공사 관광데이터 활용 공모전 출품을 목표로 개발 중입니다. 결과와 회고는 마무리되는 대로 이 자리에 채웁니다.

### 나의 활동 — 협업 구조

[저장소] **모노레포** — frontend · backend · docs 를 한 저장소에 [배포] docker **compose.yml** [브랜치] main → develop → feature/* [리뷰] feature → develop **Merge Request** 필수 [관리] Notion — 요구사항 정의서 · API 명세

### 핵심 성과 · Key Achievements

- **DERO의 협업 절차를 그대로** 이슈 컨벤션 · API 명세 사전 정리 · PR 리뷰를 그대로 가져왔습니다. **매번 새로 만들지 않아도 되는 상태**가 된 것이 이 프로젝트의 출발점입니다

- **요구사항·명세·코드를 한 히스토리에** 요구사항이 바뀌면 **명세와 코드가 같은 커밋 범위**에서 함께 움직입니다

- **develop 병합은 리뷰 필수** 지금은 인원이 적어 리뷰가 형식에 가깝지만, **사람이 늘었을 때 절차를 새로 만들지 않기** 위해 먼저 뒀습니다
