## 개요

### 진행 상황

한국관광공사 관광데이터 활용 공모전 출품을 목표로 개발 중입니다. 결과와 회고는 마무리되는 대로 이 자리에 채웁니다.

### 나의 활동 — 협업 구조

[저장소] **모노레포** — frontend · backend · docs 를 한 저장소에 [배포] docker **compose.yml** [브랜치] main → develop → feature/* [리뷰] feature → develop **Merge Request** 필수 [관리] Notion — 요구사항 정의서 · API 명세

DERO에서 만든 절차(이슈 컨벤션 · API 명세 사전 정리 · PR 리뷰)를 그대로 가져와 시작했습니다. **매번 새로 만들지 않아도 되는 상태**가 된 것이 이 프로젝트의 출발점입니다.

### 핵심 성과 · Key Achievements

- **절차를 처음부터 세우고 시작** DERO에서 만든 협업 절차(이슈 컨벤션 · API 명세 사전 정리 · PR 리뷰)를 그대로 가져왔습니다. **매번 새로 만들지 않아도 되는 상태**가 된 것이 이 프로젝트의 출발점입니다

- **모노레포 구성** frontend · backend · docs를 **한 저장소**에 두어 요구사항 · API 명세 · 코드가 같은 히스토리 위에서 움직이게 했습니다

- **브랜치 전략과 리뷰** `main → develop → feature/*` 로 고정하고 feature에서 develop으로 갈 때 **Merge Request 리뷰를 필수**로 뒀습니다

- **진행 중** 한국관광공사 관광데이터 활용 공모전 출품을 목표로 개발 중입니다. 결과와 회고는 마무리되는 대로 이 자리에 채웁니다
